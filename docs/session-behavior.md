# 截图会话交互规则（内核 ls_session 实现，两端只转发事件）

本文是 `lemonshot.h` 会话接口的行为契约。坐标为逻辑点、屏幕左上角为原点。`px = 1 / scale`（一个像素对应的逻辑长度）。

## 通用

- 选区坐标始终对齐到像素：x、y、w、h 都是 `px` 的整数倍（拖动时四舍五入到最近像素）。
- 选区夹在屏幕内。最小尺寸 `min_selection`（逻辑点），拖出的选区小于它就作废。
- 拖动阈值：按下后移动超过 3pt 才算拖动，否则算单击。
- `ls_session_selection_pixels`：x0 = floor(x·scale + 0.5)，x1 = floor((x + w)·scale + 0.5)，w = x1 − x0；y 同理。
- 每个输入函数返回 `LS_EV_*` 位掩码，平台据此重画/换光标/摆工具栏/处理动作。

## SELECTING（无选区）

| 输入 | 行为 |
|---|---|
| 移动 | `hover` = 包含光标的最上层窗口（`detect_windows` 关闭或都不包含时 = 整屏），夹到屏内；光标 `CROSSHAIR`；`show_magnifier` = 1 |
| 左键拖动 | 从按下点拉出选区（`dragging_selection`），Shift 锁定 1:1，拖动中按数字键锁定比例（见下），松开后选区 ≥ 最小尺寸则进入 SELECTED，否则回到 SELECTING |
| 左键单击 | 无 Shift：选区 = `hover`，进入 SELECTED；`hover` 是窗口时 `selection_window` = 该窗口编号（之后拖出、拉伸、移动选区或回到 SELECTING 即变 0，平台据此按窗口截图加圆角阴影）。按住 Shift：把 hover 窗口加入/移出多选集合（整屏 hover 不能多选），选区 = 集合外接矩形，`window_count` = 集合大小，进入 SELECTED；集合清空时回到 SELECTING |
| 右键 | `CANCEL` |
| Esc | `CANCEL` |
| 回车 | 选区 = `hover`（同单击，记 `selection_window`），进入 SELECTED，再发 `DONE` |
| F（绑定） | 选区 = 整屏，进入 SELECTED |
| D（绑定） | 有上次区域：选区 = 上次区域（夹到屏内），进入 SELECTED；没有：发 `LAST_AREA` |
| R/H/C（绑定） | 发 `COPY_RGB` / `COPY_HEX` / `COPY_CUSTOM` |
| 鼠标离开 | `mouse_inside` = 0，`has_hover` = 0 |

比例锁定（只在拖出或拉伸选区时，按数字键）：0 自由、1 为 1:1、2 为 4:3、3 为 3:2、4 为 16:9、5 为 16:10、6 为 3:4、7 为 2:3、8 为 9:16、9 为 21:9。锁定后以按下点为固定角，宽度跟随光标、高度按比例；超出屏幕时两边一起缩小。松开鼠标后 `ratio_index` 保留显示到下一次拖动开始。

## SELECTED（有选区）

### 光标与命中（优先级从高到低）

1. 正在拖动：保持拖动开始时的光标。
2. 选区控制点（四角 + 四边中点，命中框 `handle_hit`）：对应缩放光标。`lock_selection` 时跳过 2、3。
3. 选区边（`edge_hit` 宽的带状区域）：对应缩放光标。
4. 已有标注（最上层先命中）：`POINTER`；选中标注的控制点：对应缩放光标（端点用 `MOVE`）。
5. 选区内：工具 NONE → `MOVE`；文字工具 → `IBEAM`；其他工具 → `CROSSHAIR`。
6. 选区外：没有标注时 `CROSSHAIR`（可以重新拖出选区）；有标注时 `ARROW`。

### 鼠标

| 输入 | 行为 |
|---|---|
| 拖控制点/边 | 拉伸选区（Shift 保持当前宽高比，数字键锁比例），对边固定；拉过对边时翻转 |
| 选区内拖（工具 NONE，未命中标注） | 移动选区（夹在屏内） |
| 命中标注后拖 | 选中并移动该标注；拖选中标注的控制点 → 改形状 |
| 选区内拖（有工具，未命中标注） | 新建该工具的标注，见「标注」 |
| 选区外拖 | 没有标注：丢弃原选区重新拉出；有标注：无效 |
| 单击空白处 | 取消选中标注 |
| 双击（工具 NONE，未命中标注，选区内） | 发 `DOUBLE_CLICK` |
| 双击文字标注 | 进入文字编辑（`TEXT_BEGIN`） |
| 右键 | 正在画 → 放弃这一笔；否则 `right_click_exits` 或 `lock_selection` → `CANCEL`；否则清空选区和全部标注回到 SELECTING |
| 滚轮 | 见「滚轮」 |

新建标注时自动选中它（显示控制点）。按下点在选区外时不新建。

### 键盘

| 键 | 行为 |
|---|---|
| Esc | `CANCEL` |
| 回车 | `DONE` |
| 主修饰键+C / S | `COPY` / `SAVE` |
| 主修饰键+Z | 撤销；主修饰键+Shift+Z 或主修饰键+Y：重做 |
| Delete / Backspace | 删除选中标注 |
| 方向键 | 选中了标注：移动标注 1 像素；否则移动选区 1 像素；按住 Shift：选区右/下边伸缩 1 像素（→↓ 变大、←↑ 变小）；按住 Alt：步长 10 像素。`lock_selection` 时只能移动标注 |
| 数字键（绑定） | 拖动选区时锁比例；否则切换对应工具（再按一次回到 NONE） |
| 字母（绑定） | S `LONGSHOT`、O `OCR`、T `TRANSLATE`、P `PIN`、V `RECORD`、F 全屏选区（有标注时无效）、D 上次区域（有标注时无效）、R/H/C 复制颜色、Tab 显隐工具栏 |

多选窗口模式（`window_count > 0`）下标注工具、长截图、录屏无效。

### 滚轮（每格）

- 光标在某个标注上：该标注不透明度 ±0.05（0.05–1），连续滚动合并为一次撤销记录。
- 否则按当前工具调样式（同时作用于选中的同类标注）：矩形/椭圆/直线/箭头/画笔线宽 ±1（1–30）；马赛克块大小 ±1（2–60，画笔样式改笔刷 ±2，4–120）；文字字号 ±1（8–200）；序号「下一个」±1（1–999）；放大镜倍数 ±0.5（1.5–6）；局部高亮遮罩深浅 ±0.05（0.1–0.95）。
- 没有工具且不在标注上：无效。

## 标注

### 新建

| 工具 | 操作 | 约束 |
|---|---|---|
| 矩形、椭圆、局部高亮、马赛克矩形样式（0、2） | 拖出对角 | Shift 正方形/圆；小于 2pt 作废 |
| 直线、箭头 | 拖出起止点 | Shift 角度吸附 45°；长度小于 2pt 作废 |
| 曲线箭头（箭头样式 3） | 拖出起止点 | 控制点默认 = 中点沿法线偏移长度的 20%（向左） |
| 画笔、马赛克画笔样式（1、3） | 按住拖动记录点（相邻点距 ≥ 1pt） | Shift 画直线 |
| 文字 | 单击放置，立即 `TEXT_BEGIN` | 输入框左上角 = 单击点 −(4, font_size·0.7) |
| 序号 | 单击放置圆心，数字 = 当前「下一个」，之后「下一个」+1（发 `LS_EV_TOOL`） | |
| 放大镜 | 从圆心拖出半径（≥ 12pt）；单击 = 半径 60pt | |

### 控制点

- 矩形、椭圆、局部高亮、马赛克矩形样式：8 个（四角 + 四边中点）。
- 直线、箭头：2 个端点；曲线箭头再加 1 个控制点。
- 放大镜：圆心正右方 1 个（改半径）。
- 画笔、马赛克画笔、文字、序号：无控制点，只能移动。

### 命中

- 描边类：到路径距离 ≤ max(线宽/2 + 4, 6)。
- 实心矩形/椭圆、局部高亮、马赛克、放大镜：工具为 NONE 时区域内都算命中；**选着绘图工具时只有边框附近（到边框距离 ≤ 6）算命中**，内部可以直接开始画新标注。
- 文字、序号：外接框内。
- 选中标注的控制点始终优先于以上规则。

### 几何（`ls_shape_view`）

- 矩形：`stroke` = 矩形（圆角 `corner_radius`）；实心时 `fill` 同形、不描边。椭圆同理。
- 直线：`stroke` = 线段；样式 1 虚线（`dashed`）。
- 箭头，记 w = 线宽，L = 长度，头长 h = clamp(4w + 6, 10, 0.6L)：
  - 样式 0 实心箭头：`fill` 一个多边形：尾端宽 0.35w → 头根部宽 w 的锥形箭杆 + 三角形头（头长 h，底边全宽 0.9h），尖端在终点。不描边。
  - 样式 1 线条箭头：`stroke` = 线段 + 终点处两条 ±28° 的头线（长 h）。
  - 样式 2 双向：样式 1 两端都有头。
  - 样式 3 曲线：`stroke` = 起点→控制点→终点的二次曲线（升为三次），`fill` = 终点处按切线方向的实心三角头（长 h、底宽 0.9h）。
- 画笔：点列用中点二次平滑后升三次作为 `stroke`；荧光笔（样式 1）线宽 ×3、不透明度 ×0.4、端点平头视觉由平台按圆头处理即可。
- 马赛克：`patch` = 冻结画面对应像素区域做像素化（块 = block_size·scale 像素）或模糊（半径 = block_size·scale），画笔样式再乘以笔刷形状的透明度（圆形笔刷沿路径，边缘 1 像素抗锯齿）。`patch_rect` 为逻辑点矩形。
- 文字：`text_rect` 左上角为放置点，宽高由测量回调得到（空文字按一个字宽、一行高）；样式 0 普通（`text_color` = 颜色）；1 描边（`text_outline` = 颜色亮度 < 0.5 时白色否则黑色）；2 底色（`text_background` = 颜色，`text_color` = 对比色）。`bounds` 外扩 4pt。
- 序号：直径 d = `line_width`（大小）。样式 0 实心圆：`fill` 圆，`text_color` 白（颜色太亮时黑）；样式 1 空心：`fill` 白色圆 + `stroke` 圆（线宽 d/12），`text_color` = 颜色；样式 2 方块：`fill` 圆角方（圆角 0.2d），文字同样式 0。`text` = 数字，`text_size` = 0.55d，`text_rect` = 外接框。
- 放大镜：`p0` 圆心，`radius` 半径，`magnify_src` = 以圆心为中心、边长 2·radius/zoom 的正方形，`stroke` = 圆（线宽 `line_width`，默认 3）。
- 局部高亮：每个高亮形状本身没有绘制内容（选中时只显示控制点）；所有高亮形状合成一个 `LS_SHAPE_MASK` 放在列表最前：`fill` = 选区矩形 + 各高亮圆角矩形（奇偶规则挖空），`style.opacity` = 第一个高亮形状的遮罩深浅。

### 撤销

每次提交（新建、移动结束、改形结束、删除、改样式、文字编辑结束、一组连续滚轮）前保存整份标注列表快照。最多 100 步。选区变化不进撤销。

## 摆放

- 工具栏：x = 选区右 − w，y = 选区下 + gap；y + h > 屏高 − margin 时放选区上方（y = 选区上 − gap − h）；仍 < margin 时放选区内右下角（y = 选区下 − h − gap）。x 夹在 [margin, 屏宽 − w − margin]。
- 尺寸提示：x = 选区左，y = 选区上 − h − gap；y < gap 时放选区内左上角（x = 选区左 + gap，y = 选区上 + gap）。没有选区时以光标为准（在光标右上方）。
- 放大镜：(光标 + offset)；右边超屏时放光标左侧，下边超屏时放光标上方。
- 样式面板：x = anchor_x − 16，夹在 [margin, 屏宽 − w − margin]；工具栏在选区下方（或选区内）时 y = 工具栏下 + gap，放不下改为工具栏上 − gap − h；工具栏在选区上方时反之。
