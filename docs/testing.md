## macOS 专项

- 权限：首次截图触发「屏幕录制」授权；授权后不重启也能用（或按提示重启）。辅助功能（长截图自动滚动）、输入监控（录屏按键显示）、麦克风、摄像头被拒后的提示与「去授权」跳转。
- macOS 15 起每月一次的「继续允许录屏」确认弹出时程序行为正常。
- 截图后切回原来的应用（设置开启时）；文字识别/翻译窗口不被前台应用盖住。
- 菜单栏图标深浅色；录制中红点与计时；左键停止、右键菜单。
- 全屏应用（如全屏的 Safari）上能截图、录屏。
- macOS 11–12.2 的老路径（CGWindowListCreateImage、CGDisplayStream）有条件时测一次。

## Windows 专项

- Win7（x86 与 x64 各一台，未装任何运行库更新）：能启动；截图、标注、贴图、文字识别；录屏走 GDI 路径（光标可能闪）；翻译需要系统已装 KB3140245 才能用 TLS 1.2。
- Win8.1、Win10 1809、Win10 22H2、Win11 24H2/25H2：基本流程。
- 混合 DPI 多屏：截图层、贴图、录屏控制条、按键浮层的位置与尺寸。
- 前台焦点：快捷键或托盘触发后截图层能拿到键盘；连按两下 Alt 不弹系统菜单。
- 截光标下窗口：Chrome、Edge、UWP（设置、计算器）窗口不出黑屏。
- 录屏：Intel/NVIDIA/AMD 显卡硬件编码；没有硬件编码时退回软件；N 版或服务器没装 Media Foundation 时提示并能改录 GIF；DXGI 在副屏/独显/旋转屏上；录制中切换默认音频设备；UAC 弹窗或改分辨率时不中断。
- Win10 2004 前后：控制条、长截图面板是否进画面。
- 「在所有桌面显示」（未公开接口）在 Win10、Win11 各测一次。
- ARM64 版（Win11 ARM 设备）：启动、截图、文字识别速度。
- 服务器版（2012 R2 / 2016 / 2022 带桌面体验）：启动与截图。
